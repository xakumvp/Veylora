# Changelog

## [0.1.0] — MVP

### Добавлено
- Визуальный редактор Workflow: холст, drag & drop, соединения, multi-select, мини-карта, Undo/Redo.
- Nodes: Manual Trigger, HTTP Request, Condition, Delay, Logger.
- Движок на Go: валидация графа, обнаружение циклов, ветвление, передача переменных `{{node.field}}`, отмена.
- Execution Panel: статусы в реальном времени, логи с фильтром уровней, история запусков.
- Хранение в SQLite, автосохранение.
- Импорт и экспорт JSON с проверкой версии схемы и удалением секретов.
- Защита: только http/https, блокировка локальной сети по умолчанию, лимиты времени и размера, маскирование секретов.
