# Changelog

## [0.3.0] — Integrations & Processing (Phase 4)

### Добавлено
- Обработка данных:
  - JSON Parser (`data.json_parse`): парсинг JSON с прямой доступностью полей `{{json.fieldName}}` и исходного значения `{{json.data}}`.
  - JSON Builder (`data.json_build`): создание JSON из пар ключ-значение (с автоматическим приведением типов) или по шаблону.
  - Regex (`data.regex`): поиск первого совпадения, извлечение всех совпадений, замена текста, проверка наличия и именованные группы захвата.
  - Base64 (`data.base64`): кодирование и декодирование строк, поддержка URL-safe алфавита.
  - Hash Generator (`data.hash`): расчёт криптографических хешей MD5, SHA-1, SHA-256, SHA-512.
  - Date / Time (`data.date`): форматирование дат, смещения (дни, часы, минуты, секунды), unix timestamp и ISO 8601.
- Утилиты:
  - UUID (`utility.uuid`): генерация уникальных идентификаторов UUID v4.
  - Random Value (`utility.random`): генерация случайных чисел в диапазоне и строк заданной длины с выбором набора символов.
- Уведомления:
  - Telegram (`notification.telegram`): отправка сообщений в чаты и каналы через Bot API с поддержкой HTML и MarkdownV2.
  - Discord (`notification.discord`): отправка сообщений в каналы через Discord Webhook с поддержкой кастомного имени и аватарки.
- Файловая система:
  - Read File (`fs.read`): безопасное чтение файлов из разрешённых каталогов с контролем размера и кодировки (UTF-8 / Base64).
  - Write File (`fs.write`): безопасная запись и дозапись (append) в файлы с автоматическим созданием подкаталогов.
- Безопасность:
  - Строгая изоляция файловых операций в пределах разрешённых каталогов (`AllowedDirectories`), защита от Path Traversal и перехода по символическим ссылкам.
  - Автоматическое маскирование токенов ботов Telegram и вебхуков Discord в логах и экспорте через `Redactor`.
- UI:
  - Новые категории в библиотеке нод: `Data Processing`, `Filesystem`, `Notifications`.
  - Иконки Lucide и цветовая кодировка категорий.
  - Информативные превью для всех новых нод на холсте.

## [0.2.0] — Core Automation

### Добавлено
- Планировщик: Cron Trigger (с часовым поясом), Interval Trigger, однократный Schedule Trigger, File Watcher, Application Startup.
- Переключатель «Авто» для Workflow, восстановление расписаний после перезапуска, отображение ближайшего запуска.
- Обработка ошибок: Retry с exponential backoff, таймаут Node, таймаут Workflow (статус TIMEOUT), Continue On Error, выход ERROR, Node Stop Workflow.
- Переменные: `{{execution.*}}`, `{{workflow.*}}`, переменные Workflow `{{variables.*}}`, переменные окружения `{{env.*}}` по белому списку.
- Параллельные запуски разных Workflow с лимитом, защита от дублирующихся запусков.
- История: источник запуска, фильтр по статусу, повторный запуск.
- Settings: разрешённые каталоги, переменные окружения, лимит одновременных запусков.
- Миграция базы данных v2 (существующие данные сохраняются).

## [0.1.0] — MVP

### Добавлено
- Визуальный редактор Workflow: холст, drag & drop, соединения, multi-select, мини-карта, Undo/Redo.
- Nodes: Manual Trigger, HTTP Request, Condition, Delay, Logger.
- Движок на Go: валидация графа, обнаружение циклов, ветвление, передача переменных `{{node.field}}`, отмена.
- Execution Panel: статусы в реальном времени, логи с фильтром уровней, история запусков.
- Хранение в SQLite, автосохранение.
- Импорт и экспорт JSON с проверкой версии схемы и удалением секретов.
- Защита: только http/https, блокировка локальной сети по умолчанию, лимиты времени и размера, маскирование секретов.
